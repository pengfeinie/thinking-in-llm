## 极速部署DeepSeek大模型

### 1. 访问硅基流动

打开硅基流动官方网站：[硅基流动](https://cloud.siliconflow.cn/i/N0iG4QMt)。

### 2. 注册账号

1. 输入手机号码，获取验证码，点击“注册”即可完成账号创建。

   ![硅基流动注册页面](images/2313631-20250213151945368-1514753039.png)

### 3. 创建API密钥

1. 登录后，进入“账户管理”中的“API秘钥”页面。

2. 点击“新建API密钥”，随意填写描述，点击“新建”即可生成秘钥。

   ![创建API秘钥](images/2313631-20250213152030390-1740116492.png)

## Cherry Studio极速配置与使用

### 1. 下载与安装Cherry Studio

访问Cherry Studio官方网站：[Cherry Studio](https://cherry-ai.com/)，下载并安装适合你系统的版本，安装过程只需“下一步”。

### 2. 配置API秘钥

1. 打开硅基流动网页，进入“API秘钥”页面，点击已创建的秘钥进行复制。

   ![秘钥复制](images/2313631-20250213152121814-741273338.png)

2. 打开Cherry Studio，进入“设置①”-“硅基流动②”，将复制的秘钥粘贴至“③”处。

   ![秘钥粘贴](images/2313631-20250213152240073-505600091.png)

### 3. 加载DeepSeek模型（以deepseek-ai/DeepSeek-V3为例）

1. 打开硅基流动网页，进入“模型广场”，找到并点击“deepseek-ai/DeepSeek-V3”模型，复制模型名称。

   ![模型选择](images/2313631-20250213152336711-657406808.png)

2. 在Cherry Studio中，进入“①设置”-“②硅基流动”，点击“③添加”，将复制的模型名称粘贴至“④”处，点击“⑤添加模型”。

   ![模型配置](images/2313631-20250213152420662-2077904893.png)

3. 点击“检查”，在下拉菜单中选择“deepseek-ai/DeepSeek-V3”，点击“确定”，出现“连接成功”字样即表示模型加载完成。

   ![模型连接](images/2313631-20250213152507125-351248625.png)

### 4. 运行与测试

1. 打开Cherry Studio，点击“①对话”，选择“②模型名称”，添加“③助手”以完成功能配置。

   ![模型加载](images/2313631-20250213152634449-308466624.png)

2. 完成上述步骤后，即可与DeepSeek进行对话。

   ![模型使用](images/2313631-20250213152712608-1153159401.png)

   **该方法同样适用于其他模型的加载，若要求不高，可选择免费模型进行使用。**

## 知识库

### 创建知识库

点击左侧 知识库 → 添加，输入知识库名称（如“test”），选择嵌入模型 BAAI/bge-m3。

![](images/11c0a42bcce2403f8945779b663f682d.png)

### 上传文档并向量化

支持上传 PDF、Word、TXT、网页链接 等格式。拖拽文件至知识库界面，等待右侧出现绿色对勾即表示向量化完成。

注意：若文档含复杂表格或扫描件，需先用工具（如Doc2x）转换为结构化文本以提高解析精度。
